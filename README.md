## About

I am an **Elektroniker (electronics technician)** in Germany, building on a practical background in electronics, electrical systems, troubleshooting, PLC technology and industrial automation.

I am now moving deeper into software and technology, with a focus on **cybersecurity, data analytics and Python**.

My approach is simple:

> **Understand the system. Build something. Break it. Find out why. Improve it.**

That mindset comes from working with real technical systems, where guessing is usually a bad debugging strategy.

## Learning philosophy

I am not trying to collect technology names.

I am building **transferable technical understanding**.

When I learn a tool, I want to understand:

1. What problem does it solve?
2. How does it work?
3. What can go wrong?
4. How do I test it?
5. How can I use it in a real project?

This is why my GitHub contains notes, experiments, assignments and projects alongside polished work.
